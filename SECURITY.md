# Security Policy

## Reporting a Vulnerability

Please do not open public issues for sensitive security vulnerabilities.

Use one of the following:
1. GitHub Security Advisory (preferred), if enabled for this repository.
2. Contact the repository maintainers directly.

Include:
1. A clear description of the issue.
2. Reproduction steps or proof of concept.
3. Affected version/commit and impact assessment.

You will receive acknowledgment as soon as possible, and we will coordinate disclosure after a fix is available.
